# Learning Deep Priors: Variational Optimization Inspired Unfolding Network for Underwater Image Enhancement

   The SDRUI  dataset contains 2270 real high-resolution degraded underwater images with multiple scenes. The dataset is divided into five subsets (i.e., Common degraded Scence, Blurred Scene, Turbid Scene, Low-light Scene, Non-uniform illumination Scene).

   The SDRUI dataset can be downloaded from [Baidu Cloud](https://pan.baidu.com/s/1kHeDGYjoLNNqHeF9FTExcg?pwd=SDUI) (Password：SDUI). 
   
   The dataset can only be used for non-commercial purpose. If you use our dataset, please cite the paper. Thanks.
