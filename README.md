# Learning Deep Priors: Variational Optimization Inspired Unfolding Network for Underwater Image Enhancements.

   The SDRUI  dataset contains 2270 real high-quality underwater images with multiple scenes. The data is divided into five subsets (BS, CS, LS, NS, TS).

   The SDRUI dataset can be downloaded from [Baidu Cloud](https://pan.baidu.com/s/1kHeDGYjoLNNqHeF9FTExcg?pwd=SDUI) (Password：SDUI).
